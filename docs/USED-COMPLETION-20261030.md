# 중고차 상품화 완료 조건 및 출고 표시

기준 a3d612a. 오류 번호 7c9efca973a34516b24cb273dc55da48는 운영 로그에서 찾지 못했으나, 상품화 완료 시 미정비·세차 미완료·잔량 미입력을 거부하는 코드와 회귀 테스트를 확인했다.

상품화 완료는 사용자의 명시적 완료 처리로 결정한다. 오일 교환, 세차, 보수, 주행거리/잔량 등 미입력은 완료를 막지 않는다. 미완료 체크를 완료로 조작하지 않으며 기존 범위/날짜/권한/버전 충돌 검사와 출고 준비 절차는 유지한다.

중고차 출고 목록과 상세 화면은 차량번호·차대번호·차종으로 간소화한다. 관리자 반품·정정 동작은 유지한다. 신차 출고 화면은 변경하지 않는다. 원본 Snapshot, 감사 이력, 사진, 재입고 회차는 그대로 보존한다. 미래 출고 유형/리스 규칙은 추가하지 않는다.

격리 DB 서버 검사 40개 통과: 미정비/미세차/미입력 상품화 완료→작업완료→출고준비→실제 출고, 미완료 원본 보존, 기존 사진/재입고/권한/잘못된 수치 검사 포함. 실제 Chrome에서 중고차 세 항목 목록/상세와 기존 공통 캘린더·신차 출고 회귀 검사 통과. 갤럭시 실기기 미검증. 새 APK 불필요.

운영 적용은 백업 후 검증 커밋 fast-forward. 코드 복구는 해당 커밋 revert를 사용하며 DB를 덮어쓰지 않는다.
