로그인 안내 수정 패치 1.0.1

원인: 잘못된 아이디/비밀번호의 401 응답도 로그인 만료로 표시했습니다.
수정: 로그인 실패에는 서버의 실제 안내를 표시하고, 기존 세션 만료와 구분합니다.
기본 설치 관리자 아이디 admin 및 설치 시 입력한 비밀번호 안내를 추가했습니다.

적용 방법
1. 서버 콘솔에서 Ctrl+C로 종료합니다.
2. 이 ZIP의 web 폴더를 기존 scooter_warehouse 폴더 안에 복사하여 덮어씁니다.
   최종 경로는 scooter_warehouse/web/app.js 및 web/sw.js입니다.
3. windows/START_LOCAL_SERVER.cmd를 다시 실행합니다.
4. 로그인 화면에서 Ctrl+Shift+R로 새로고침합니다.
5. 기본 설치였다면 아이디 admin과 최초 설치 때 지정한 비밀번호를 입력합니다.
   cschoi를 별도로 생성했다면 해당 계정을 사용합니다.

차량 DB, 계정, 비밀번호는 변경하지 않습니다. APK 재설치는 필요 없습니다.
비밀번호를 모르는 경우 DB를 삭제하거나 재설치하지 말고 복구를 요청하세요.

검증: 실제 API 함수에 대해 잘못된 계정, 만료 세션, 정상 로그인, 요청 제한
4가지 응답 처리 회귀 테스트 통과. JavaScript 구문 검사 통과.
