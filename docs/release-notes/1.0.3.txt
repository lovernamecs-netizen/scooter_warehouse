입고·삭제·지도 등록 패치 1.0.3 (PC)

적용 방법
1. 서버 콘솔에서 Ctrl+C를 눌러 종료합니다.
2. 기존 폴더의 windows/BACKUP_LOCAL.cmd로 백업해 두세요.
3. 이 ZIP의 server, web 폴더를 기존 scooter_warehouse 폴더 안에 복사해 덮어씁니다.
4. windows/START_LOCAL_SERVER.cmd로 다시 시작하고 Chrome에서 Ctrl+Shift+R로 새로고침합니다.
기존 warehouse.db를 삭제하지 마세요. DB 구조를 바꾸거나 기존 차량을 자동 변경하지 않습니다.
로그인 수정 및 지도 우클릭·격자 이동 패치가 포함되어 있습니다.

1) VIN 나중에 입력
입고 폼의 VIN을 비워 두어도 저장됩니다. 임시 관리번호와 VIN 미등록 표시로 구분됩니다.
상세 → 정보 수정 → VIN 입력 → 수정확정 순서로 추가합니다.
최초 VIN 입력은 작업자도 가능합니다. 이미 입력된 VIN 변경은 기존 관리자 확인 규칙을 따릅니다.
실제 VIN은 17자리 형식과 중복 여부를 확인합니다. VIN 미등록 상태의 실제 출고확정은 차단합니다.
파일 입고(CSV/TSV/XLSX)에서도 빈 VIN을 허용하며 빈 VIN 여러 대를 각각 구분합니다.
DB 호환을 위해 VIN 미등록 레코드에는 예약된 내부 토큰을 사용합니다.
해당 토큰은 실제 VIN이 아니며 화면/API 차량정보와 차량 원장 내보내기에는 빈 VIN과 임시번호로 표시됩니다.

2) 잘못 등록한 차량 삭제
관리자 계정으로 차량 상세 → 차량 삭제 → 사유 입력 → 확인란에 삭제 입력 → 확정.
현재 재고와 지도 자리에서 제거하고 삭제 이력을 남깁니다(논리 삭제).
주문이 배정되어 있으면 먼저 주문을 취소해야 합니다.
출고 이력이 있는 차량은 삭제하지 않고 기존 출고 정정 기능을 이용합니다.
삭제된 VIN도 이력 보존 대상이므로 동일 VIN을 새 차량으로 중복 등록할 수 없습니다.
이 패치는 과거 입고 이벤트나 이미 마감된 통계를 지우지 않습니다.

3) 지도에서 바로 등록·이동
사용 가능한 빈 Slot을 오른쪽 클릭하세요.
- 여기에 신규 차량 등록: 차종·색상 등을 입력하면 등록과 배치를 함께 저장합니다.
- 기존 차량을 여기로 이동: VIN·임시번호·차종 검색 후 차량 선택 → 이동확정.
구역 이름을 오른쪽 클릭하면 기존 구역 설정 메뉴를 이용할 수 있습니다.
신차를 정규 재고구역에 직접 등록하려면 실제 유비스 설치완료를 확인하고 체크해야 합니다.
미장착 신차는 입고/유비스 대기 구역을 사용하세요. 기존 구역 차종 제한도 유지합니다.
목적지가 다른 차량으로 찼거나 사용 불가능하면 전체 등록·배치를 취소하므로 미완성 입고가 남지 않습니다.

검증
서버 자동 테스트 및 Chromium 화면 테스트를 수행했습니다.
지도 빈자리 신규등록(VIN 공란) → 기존 차량 이동 메뉴 → VIN 추후 입력 → 삭제 후 자리 비우기 확인.
출고 전 VIN 필수 확인, VIN 중복 차단, 권한 검사, 출고이력 보호, 직접 배치 실패 롤백을 검증했습니다.
검증 스크립트는 tests 폴더에 포함합니다. Windows 실기기 확인은 적용 후 진행해 주세요.
