# 1.0.7 변경 및 설치 안내

- APK 내부 후면 카메라, 터치 초점, 확대 슬라이더, 조명.
- 촬영 후 사진에서 VIN 17자리 줄을 드래그 선택. 원본과 명암 보정 영상의 OCR 결과에서 후보 추출.
- NO 등 짧은 표제는 후보 제외. 전체 17자 토큰만 검사하고 긴 문자열의 일부를 임의로 자르지 않음. 라벨이 있는 줄의 후보 우선. O/Q→0, I→1 보정은 후보 제시만 하며 B/8, S/5를 임의 확정하지 않음.
- 연식과 제조년월(YYYY-MM)을 별도 저장·수정·조회·가져오기·내보내기. 미래 제조월은 거부하고 미확인은 비워둘 수 있음.
- 기본 재고 정렬: 제조년월 오래된 순 → 같은 월 입고일 순 → 미확인 마지막. 별도로 입고일 기준 FIFO 정렬 선택 가능. 자동 출고 배정 기능은 아님.
- 새 출고 Snapshot에 제조년월 포함. 당시 차량정보·장착품·실제 전달품은 변경 불가능한 기록으로 보존.
- APK 뒤로가기에서 작성 취소 확인. OCR 취소/확정 복귀 시 기존 입력 보존.
- 리스 사용시작·반납·고객 인수는 설계만 포함. docs/leasing-extension.md 참고.

## 카메라 사용

PC 서버와 APK를 모두 새 버전으로 변경합니다. 카메라 OCR은 APK 기능이며 Chrome은 VIN 직접 입력을 지원합니다.

카메라 권한 허용 → VIN 줄을 후면 카메라로 크게 촬영 → 사진 위를 드래그해 17자리 전체 선택 → 선택영역 인식 → 사진과 후보 비교 → 필요하면 수정 → 확인.

NO·배기량·제조일 등의 다른 줄은 선택 영역에서 제외하세요. 형태가 맞는 다른 17자리 식별자도 후보가 될 수 있으므로 반드시 원문을 확인하세요. 인식률 수치를 보증하지 않습니다.

## 기존 데이터 유지 업데이트

1. 서버를 종료하고 기존 프로그램 폴더 전체를 별도 백업합니다. 실행 중인 SQLite DB 한 파일만 복사하지 마세요.
2. 전체 ZIP을 새 폴더에 풉니다.
3. 서버가 종료된 상태에서 기존 warehouse.db를 새 scooter_warehouse 폴더에 복사합니다. 사용자 지정 실행 설정이 있으면 실제 DB 경로도 유지하세요. 기존 .venv는 복사하지 않습니다.
4. DB 복사를 마친 후 windows/START_LOCAL_SERVER.cmd를 실행합니다. 기본 실행 스크립트는 해당 폴더의 warehouse.db를 사용합니다.
5. 기존 계정으로 로그인하고 PC 화면을 Ctrl+Shift+R로 새로고침합니다. DB schema 1→2는 제조년월 컬럼만 추가합니다. 기존 위치·입출고·장착품 기록을 삭제하지 않습니다.

운영 DB에 demo/샘플 초기화를 실행하지 마세요. 기존 폴더를 먼저 삭제하지 마세요. 이전 프로그램으로 되돌릴 때는 업데이트 전 백업을 사용하세요.

APK는 시험용 서명입니다. 이번 APK는 이전 설치본과 서명이 달라 덮어쓰기가 안 됩니다. 미저장 작업을 마치고 서버 주소를 기록한 뒤 기존 휴대폰 앱을 삭제하고 새 APK를 설치하세요. 휴대폰의 초안·주소·로그인은 지워질 수 있지만 PC의 재고 DB는 휴대폰 앱 삭제로 삭제되지 않습니다. 같은 HTTPS 서버 주소로 다시 연결합니다.
