창고지도 편집 패치 1.0.2 — PC 우선

적용
1. 실행 중인 서버 콘솔에서 Ctrl+C를 눌러 종료합니다.
2. ZIP의 web 폴더를 기존 scooter_warehouse 폴더 안에 복사하여 덮어씁니다.
3. windows/START_LOCAL_SERVER.cmd로 다시 실행합니다.
4. Chrome에서 Ctrl+Shift+R로 새로고침합니다.
web/map-editor.js는 이번에 추가된 파일이므로 반드시 함께 복사하세요.
계정·재고 DB는 변경하지 않습니다. 이전 로그인 안내 수정도 포함합니다.

사용
- 관리자 계정에서 구역 안을 오른쪽 클릭 → 설정 수정.
- 지도 편집 → 구역 제목줄을 드래그 → 놓으면 자동 저장.
- 격자 간격 10 / 20 / 40 선택. 숫자는 실측 cm가 아닌 지도 좌표 단위입니다.
- 이동 중 X/Y 표시. Esc 또는 창 포커스 이탈 시 현재 드래그 취소.
- 문·통로·자재·벽 도형도 편집 모드에서 드래그 가능.
- 도형 우클릭 설정은 기존 도형 목록 편집창을 엽니다.
- 구역의 수치 좌표를 직접 입력하는 기존 기능도 유지합니다.
- 일반 모드에서는 기존 차량 끌어놓기, 편집 모드에서는 구역 제목 이동을 사용합니다.
- 구역 배치 이동은 지도 표시 위치를 변경하며, 내부 차량의 Slot ID는 유지합니다.
- 겹침은 자동으로 해소하지 않습니다. 필요하면 다른 격자 위치로 옮기세요.
- Grid 축소/비활성화 시 점유 차량 보호 검사는 기존 서버 로직을 사용합니다.
- 다른 작업과 버전 충돌 또는 통신 오류 시 실패 안내 후 서버 상태를 다시 확인합니다.

검증
임시 DB와 실제 Chromium 브라우저에서 우클릭 구역 이름 수정, 80% 축소 화면
격자 이동, Esc 취소, 새로고침 후 위치 유지, Slot ID 보존, 409 저장 거절 후
원위치 복원, 자재 도형 이동·우클릭 메뉴를 검증했습니다. JS 오류 0건.
