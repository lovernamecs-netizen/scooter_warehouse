# v1.0.6 — 입력 취소·뒤로가기 및 VIN 후보 검증 수정

## 기존 사용자 적용
1. 실행 중인 창고 서버를 종료하고 기존 프로그램 폴더 전체를 백업하세요.
2. 이 전체 압축파일은 새 폴더에 해제하세요.
3. 해제한 scooter_warehouse/web 폴더의 파일 전체를 현재 사용 중인 프로그램의 web 폴더에 덮어쓰세요. 새 파일 vin.js, form-safety.js도 포함해야 합니다.
4. 기존 폴더에서 windows/START_LOCAL_SERVER.cmd를 다시 실행하세요.
5. PC Chrome은 Ctrl+F5, 폴드 창고 앱은 완전히 종료 후 다시 실행하세요. PC 왼쪽 하단 v1.0.6 표시를 확인하세요.
warehouse.db는 삭제·교체하지 마세요. 기존 서버 주소, 사용자 계정, 재고 DB를 그대로 사용합니다.

## 변경
- 입력값이 변경된 창의 X/Esc/브라우저 뒤로가기에 저장하지 않고 닫기 확인을 표시합니다.
- OCR 결과 취소 시 입고/출고 입력창과 작성값을 복원합니다. 확인 시 VIN만 반영합니다.
- 출고 전달 수량 및 예외 사유가 OCR 전환으로 초기화되지 않게 합니다.
- 처리 중 다른 버튼 및 창 닫기를 차단해 중복 요청과 화면 전환 충돌을 줄입니다.
- 입고 페이지 갱신 때마다 신규 입고창이 자동으로 다시 열리는 문제를 수정합니다.
- NO/VIN/CHASSIS NO 등의 표제를 제거하고, 17자리 전체 토큰 또는 17자리 공백 분리 문자열만 후보로 사용합니다. 긴 문장에서 임의의 17자를 자르지 않습니다.
- I/O/Q 보정은 후보로만 제시하며, B/8·S/5는 자동 변경하지 않습니다. 사용자 확인 전에 등록하지 않습니다.
- 짧은 OCR 결과/NO만 있는 결과는 VIN으로 확정할 수 없습니다. 인식 실패 시 재촬영 또는 직접 입력을 안내합니다.
- Chrome에서는 카메라가 APK 기능임을 버튼에 명시합니다. 브라우저 OCR을 새로 구현한 버전은 아닙니다.
- 계정 화면에서 10자 미만 비밀번호는 저장 요청 전에 안내합니다.

## 검증 및 범위
격리된 테스트 DB와 Chromium 자동화로 X/Esc/브라우저 뒤로가기, 입력 폐기 확인, OCR 취소/확인 시 입고값 복원, 출고 전달 수량·사유 복원, 저장 중 닫기 차단, 취소 시 서버 명령 미전송을 확인했습니다. JavaScript 실행 오류는 없었습니다.
OCR 테스트는 표제·짧은 문자·긴 문자열·공백 분리·O/0 후보 등 인식 텍스트를 이용한 후보 추출 회귀 테스트입니다. 실제 차량 사진 인식률 향상을 측정한 것은 아닙니다.
기존 APK 1.0-test는 그대로 포함합니다. OCR 후보 검증 및 화면 취소 수정은 서버에서 전달되는 화면 코드에 적용되어 기존 APK에서도 사용됩니다.
Android 시스템 뒤로가기 버튼의 기존 '서버 주소 변경/앱 닫기/취소' 메뉴는 변경하지 않았습니다. 작성 내용을 유지하려면 이 메뉴에서 취소를 선택하거나 화면의 X/취소 버튼을 사용하세요. 앱 강제 종료·운영체제 프로세스 종료 시 작성값 복구를 보장하지 않습니다.
Windows/Fold 실제 장치에서의 뒤로가기 제스처·카메라 촬영은 별도 실사용 확인이 필요합니다.
