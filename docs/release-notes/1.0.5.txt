1.0.5 여러 창고·외곽 편집 패치 (2026-10-06)

적용
1. 기존 windows/BACKUP_LOCAL.cmd로 백업을 만드세요.
2. 서버 콘솔에서 Ctrl+C로 종료합니다.
3. ZIP의 server와 web 폴더를 기존 scooter_warehouse 폴더에 덮어씁니다.
   새 파일 server/warehouses.py도 반드시 복사하세요.
4. windows/START_LOCAL_SERVER.cmd로 실행하고 Ctrl+Shift+R로 새로고침합니다.
기존 warehouse.db를 삭제하지 않습니다. 앞선 1.0.1~1.0.4 기능도 포함합니다.

창고 추가
창고지도 → 창고 추가 → 이름과 가로/세로 크기, 외곽 형태 선택 → 창고 저장.
20~30대 수용 창고를 미리 고정 생성하지 않습니다. 실제 이름과 형태를 지정하세요.
창고 추가 후 지도 편집 → 구역 추가에서 행/열을 지정합니다.
예: 3행 × 10열은 30개 자리입니다. 실제 통로/작업 공간을 고려해 정하세요.
숫자는 지도 좌표 단위이며 실제 m 또는 cm가 아닙니다.

창고 이름·외곽
상단 ‘창고 이름·외곽’에서 이름, 가로/세로 크기를 변경합니다.
직사각형, ㄱ자형, ㄷ자형 또는 직접 입력한 외곽 다각형을 사용합니다.
직접 입력은 [가로,세로] 꼭짓점 목록입니다. 각 축은 0~1000 비율 좌표이며
왼쪽 위 [0,0], 오른쪽 아래 [1000,1000]입니다. 점을 외곽 순서대로 입력하고
첫 점을 끝에 반복하지 마세요. 교차하는 다각형은 저장되지 않습니다.
크기와 형태 변경이 기존 구역/도형을 외곽 밖으로 밀어내면 변경을 차단하고
해당 구역/도형 이름을 안내합니다. 기존 위치를 먼저 이동/축소한 뒤 적용하세요.

창고 수 줄이기
창고 목록 → 설정 → ‘창고 사용’ 체크 해제 → 저장·확인.
차량이 남아 있으면 중지되지 않습니다. 차량을 다른 창고로 먼저 이동하세요.
최소 한 개의 창고는 유지해야 합니다. 영구삭제 대신 사용 중지하며
창고 목록에서 재활성화하면 원래 구역과 Slot ID가 그대로 복원됩니다.

창고별 배치와 이동
지도 상단의 창고 선택으로 전환합니다. 구역·도형·배치 대수·자리 수를
각 창고별로 표시합니다. 전체 재고와 일 마감은 모든 창고 합계입니다.
미배치 차량은 아직 창고가 지정되지 않은 공통 목록입니다.
차량 상세 → 위치이동 → 목적 창고 선택 → 빈자리 선택 → 이동확정.
빈자리에 우클릭/터치하여 기존 차량 이동을 선택하는 방법도 유지합니다.
위치 표시에 ‘창고 · 구역 · Slot’을 표시하며 이동 이력에도 창고를 기록합니다.
차량이 들어 있는 구역의 소속 창고를 통째로 바꾸는 것은 차단합니다.
실제 차량을 다른 창고의 자리로 옮겨야 합니다. 빈 구역의 소속은 수정 가능합니다.

기존 데이터
기존 구역·차량·문/통로 도형은 ‘기존 창고’ 한 곳으로 자동 표시됩니다.
기존 창고 외곽은 기존 배치가 들어가도록 계산됩니다. 그 이름을 본창고 등으로
바꾸어 사용하세요. 차량과 Slot ID는 유지하며 DB 테이블을 재작성하지 않습니다.
창고 설정과 구역 소속은 기존 Settings 저장소와 배치 변경 Snapshot에 보존합니다.
백업에 포함되며 XLSX 내보내기에 WAREHOUSES / ZONE_WAREHOUSES / MAP_OBJECTS를 추가했습니다.

검증
서버 자동 테스트: 여러 창고, 창고 간 차량 이동, 점유 창고 사용 중지 차단,
외곽 축소/다각형 교차 차단, 재활성화 시 Slot 보존, 기존 배치의 자동 연결 확인.
Chromium: 창고 이름 변경, ㄱ자 창고 추가, 30자리 생성, 창고 전환·새로고침,
외곽 축소 경고, 사용 중지·복원 확인. Windows 실사용 검증은 적용 후 필요합니다.
