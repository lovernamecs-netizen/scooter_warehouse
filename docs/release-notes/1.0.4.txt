1.0.4 PC 제목 표시줄·Android 연결 패치

PC 적용
1. 실행 중인 창고 창과 서버를 종료하고 기존 데이터 백업을 권장합니다.
2. ZIP의 web, server 폴더를 기존 scooter_warehouse 폴더에 덮어씁니다.
3. START_LOCAL_SERVER.cmd로 다시 실행합니다. Ctrl+Shift+R로 새로고침한 뒤
   창고 창을 완전히 닫았다가 ScooterWarehouse.exe로 다시 여세요.
4. 우측 상단 최소화·최대화·닫기 버튼의 표시를 확인하세요.

UI 본문 배치·색상은 유지했습니다. 제목 표시줄의 테마 색을 밝게 지정하고
문서에 light color-scheme을 지정했습니다. Windows/Chrome가 그리는 네이티브
창 버튼을 웹의 가짜 버튼으로 대체하지 않습니다.
첨부 화면에서 버튼은 존재하지만 어두운 배경·아이콘으로 보였습니다.
이 환경에서 Windows 네이티브 제목 표시줄을 재현하지 못했으므로 실제 효과는
사용자 PC에서 확인해야 합니다. 여전히 어두우면 Chrome 일반 창에서
http://127.0.0.1:8765 를 열어 테스트하고, 제목 표시줄을 포함한 화면을 보내주세요.
참고: https://web.dev/learn/pwa/web-app-manifest (theme_color의 데스크톱 제목 표시줄 적용)

Android APK
기존 ScooterWarehouse-1.0-test.apk를 사용합니다. 새 네이티브 빌드를 한 것은 아닙니다.
기존 서명된 파일과 바이트가 일치함을 검증했습니다.
APK는 서버 화면을 불러오므로 이 패치를 서버에 적용하면 최신 기능을 사용합니다.
휴대폰에서 빈 Slot 터치 → 여기에 신규 등록 / 기존 차량 이동 메뉴를 추가했습니다.
카메라 VIN OCR 및 접기·펼치기 대응은 기존 APK에 포함되어 있습니다.

휴대폰 사용 절차
1. 외부에서 접근 가능한 공통 HTTPS 서버에 최신 서버·web 파일을 설치합니다.
2. APK를 설치하고 첫 화면에 그 HTTPS 서버 주소를 입력합니다.
3. PC 실행기도 동일한 HTTPS 주소를 사용합니다.
4. 서버에서 만든 계정으로 로그인합니다.
PC의 127.0.0.1 주소는 폰 LTE에서 사용할 수 없습니다.
외부 서버/도메인은 아직 배포하지 않았으며 이 패치에 공용 서버 주소는 없습니다.
PC 로컬 DB를 서버로 이전할 경우 기존 백업·복구 절차를 통해 빈 서버 DB로 옮깁니다.
PC와 서버에 서로 다른 재고를 동시에 입력하지 마세요.

884px로 펼친 뒤 입력값 유지, 삭제 후 Slot 비움: Chromium 브라우저 검증 통과.
