ScooterWarehouse 1.0.9 누적 업데이트 — 1.0.7 / 1.0.8용

적용 순서
1. 직원들의 입력을 마치고 PC 창고 프로그램과 서버 창을 모두 종료합니다.
2. ZIP을 별도 임시 폴더에 압축 해제하고 APPLY_UPDATE.cmd를 실행합니다.
3. 현재 사용 중인 warehouse.db가 들어 있는 기존 scooter_warehouse 폴더의 전체 경로를 입력합니다.
4. 종료 확인 문구 UPDATE를 입력하고 완료 메시지를 확인합니다.
5. 기존 프로그램 폴더에서 서버를 다시 실행합니다. PC는 Ctrl+F5, 휴대폰은 앱/브라우저를 닫았다가 다시 엽니다.
6. PC 왼쪽 아래 v1.0.9 표시를 확인합니다.

Python 3.12를 사용합니다. APK 1.0.7은 재설치하지 않아도 연결한 서버의 변경 화면을 사용합니다.
기존 DB를 교체하지 않습니다. 적용 전 update_backups 폴더에 DB와 변경 대상 파일을 자동 백업합니다.
1.0.7 또는 1.0.8 기준 파일과 다르거나 기존 DB가 없는 폴더이면 적용을 중단합니다.
별도의 DATABASE_URL을 사용하는 설치는 자동 업데이트 대상이 아닙니다.

변경 1 — VIN의 S / 5 확인
카메라 OCR 결과 아래에 17자리 문자와 각 위치 번호를 표시합니다.
S와 5를 강조하며, 예를 들어 '6번째 S → 5' 버튼으로 해당 문자만 바꿉니다.
다시 누르면 원래 문자로 되돌릴 수 있습니다. 여러 위치에 혼동이 있으면 각각 바꿀 수 있습니다.
촬영 사진과 확인한 뒤 '사용자 확인 완료'를 누릅니다. 기존 작성 정보는 보존합니다.
PCX의 특정 위치를 무조건 숫자로 간주하지 않습니다. S를 모두 5로 자동 치환하지 않습니다.
이번 개선은 서버에서 제공하는 OCR 결과 검수·보정 화면입니다. APK의 카메라/ML Kit 인식 엔진을 변경하거나 인식률을 실측한 것은 아닙니다.
실제 PCX 스티커 촬영 결과에서 추가 개선이 필요하면 혼동된 VIN 부분만 잘라서 제공해 주세요.

변경 2 — 유비스 미장착 차량의 배치
미장착 신차도 입고 시 지정 칸 배치, 정규 재고구역 배치, 창고 간 이동이 가능합니다.
미장착 차량이 있다고 구역 이름/배열 변경을 막지 않습니다.
차종 허용 설정, 점유 충돌, 비활성 칸, 점유 칸 축소 방지는 유지합니다.
신차의 '작업완료' 및 '출고대기로 이동' 시에는 유비스 설치완료를 확인합니다.
중고차의 기존 유비스 예외와 관리자 사유를 남기는 예외 출고 기능은 유지합니다.
유비스 미장착 상태를 설치완료로 바꾸거나 기존 차량 데이터를 자동 수정하지 않습니다.

변경 3 — 제조년월 가독성
현재재고 카드/표, 지도 차량 칸, 출고대기 카드, 차량 상세에 제조년월 배지를 표시합니다.
확인된 제조년월은 파란 바탕의 굵은 숫자, 미입력 차량은 주황색 '제조 미확인'으로 표시합니다.
연식과 제조년월은 별개로 유지하고 추정값을 채우지 않습니다.
기존 제조년월 오래된 순 정렬과 입고일 순 정렬을 그대로 지원합니다.
기존 지도 크기/칸 위치를 바꾸지 않았습니다.

1.0.8 기능도 포함
창고별 출고대기 카드, 장착품 1개 태그, Android 키보드 대응을 포함합니다.
처음 적용 시 이미 출고대기였던 차량은 실물을 확인하고 '출고대기로 이동'을 눌러 주세요.
출고대기 차량은 실제 출고확정 전까지 재고이며, 실제 출고 실적에는 포함하지 않습니다.

백업 및 복구
적용 중 일반적인 쓰기 오류가 발생하면 변경 파일을 되돌립니다.
전원 중단 등으로 업데이트가 중간에 끝나면 서버를 실행하지 말고 백업 폴더를 보존해 주세요.
업데이트 후 새로 입력한 데이터가 있으면 이전 DB 백업으로 무작정 덮어쓰지 마세요.
이 업데이트는 이전에 분실했다고 보고한 데이터의 복구를 수행하지 않습니다.
