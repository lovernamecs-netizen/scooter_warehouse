# 공용 보험증권함 — 2026-11-05

기준 운영: 06459ca. 개발 브랜치는 검증된 차량번호/파일명 검색 커밋 511777e에서 이어진다. 운영 DB/사진/환경 미변경, 원격 push 및 배포 미실행.

## 사용자 동작
- 보험증권·MMS 상단에 공용 증권함. 최초 admin 및 활성 관리자 모두 목록/검색/미리보기/다운로드/등록/경로 설정 사용. 작업자와 미로그인 사용자 API 차단.
- 기존 고객정보·MMS 발송 권한은 확대하지 않음. 공용 증권함 권한과 별개로 기존 발송 권한 확인 유지.
- 서버 PC 저장 경로를 표시하며 관리자가 절대 경로 입력. 기본 제안은 DB 옆 Data/InsuranceDocuments(WAREHOUSE_DATA_DIR 사용 시 해당 데이터 루트 하위). 빈 전용 폴더만 신규 지정. 소스/웹/.git/네트워크 공유 경로 금지. 다른 PC에서 입력해도 서버 PC 경로다.
- 경로 변경은 이후 등록부터 적용. 과거 경로와 파일은 유지하고 계속 조회. 임의 파일 이동/덮어쓰기/삭제 없음.
- PDF 변환 후 ‘현재 검색 결과 공용 저장’, 또는 ‘JPEG 폴더 공용 등록’. 원본 확인 전 상태도 함께 기록하고 발송 준비로 가져올 때 다시 확인. 등록 완료된 항목만 서버에 영구 보관된다.
- 같은 파일 내용 SHA-256은 전역 유일. 재시도/동시 등록도 기존 문서 반환. 파일명/차량번호가 다르면 기존 정보 유지 안내. 원본 내용을 덮어쓰거나 추정 수정하지 않음.
- 같은 차량번호의 다른 JPEG는 별도 문서로 보존. 등록일/등록자/같은 차량번호 문서 수 표시. 자동 최신본 선택·자동 발송 없음.
- 원본 및 메타데이터 Fernet 암호화. JPEG 다운로드 시 원본 bytes 복원, 추가 재압축 없음. 디스크 .enc 파일을 직접 이미지 뷰어로 여는 방식이 아님. 원본 JPEG 199,000바이트/1500×1440 제한 유지. 암호화 저장 파일은 원본보다 커진다.

## 성능·안정성
- SQL 색인과 HMAC 검색용 1~3글자 조각 사용. 메타데이터 평문 검색 색인 없음. 후보에 정확 부분 문자열 대조.
- 목록은 최대50건 + 다음 페이지 커서. 원본 이미지/base64 제외. 선택 시에만 다운로드. 모바일 공용 목록은 카드형 표시.
- 공용 폴더 등록은 파일 메타 목록만 취득하고 최대4개 JPEG만 읽어 전송. 전체 JPEG를 브라우저 배열에 쌓지 않음. 중단은 현재 진행중 요청 완료 후 신규 요청 정지. 완료 항목 보존, 재선택 시 해시 중복 방지.
- 이미지 먼저 atomic 쓰기/fsync 후 DB 및 검색 색인/감사 기록 동일 트랜잭션. 파일 오류 시 DB 미기록. DB 커밋 실패 시 참조 없는 암호화 파일이 남을 수 있으나 정상 문서/기존 파일 삭제하지 않음. 자동 orphan 삭제 기능 없음.
- immutable DB 문서/색인, 다운로드 파일해시/암호문 및 복호화원본 검증. 등록/중복/읽기/경로 변경에 관리자 감사 기록.
- 통합 백업에 활성/이전 경로의 암호화 파일/경로 marker 포함. 복구 시 새 폴더로 경로 재매핑. 기존 고객정보 암호화 키 및 별도 암호화 키 복구본이 있어야 해독 가능. 키는 Git/백업 ZIP에 평문 포함하지 않음.
- 브라우저 테스트 설정은 테스트 전용 MMS 설정·가짜 인증값으로 격리하여 운영 Windows 보안 저장소/설정을 읽거나 쓰지 않도록 보완.
