## 동작
- 지도 확대/축소 버튼 옆 ‘지도 이동’으로 켜고 끈다. 켜진 상태는 버튼과 안내에 표시.
- 켜면 한 손가락으로 지도 이동, 두 손가락 간격으로 확대·축소. 두 손가락을 평행 이동할 때 배율/위치가 변하지 않는다.
- 두 포인터 갱신을 requestAnimationFrame에서 함께 계산하고 8px 또는 초기 거리 4% 이하 흔들림을 무시한다. 핀치 시작 중심을 유지해 이동과 배율 변경을 구분한다.
- 이동 모드 중 차량 선택, 2초 누르기, 우클릭, 차량 드롭을 차단. 지도 편집과 동시에 켜지지 않는다. 상세에서 차량 이동을 시작하면 지도 이동 모드를 끈다.
- 모드를 끄면 기존 조작 유지. PC 빈 공간 왼쪽 드래그, +/− 버튼, 세 손가락 UI 배율 조작 유지.
- 화면 위치/배율만 바꾸며 DB 저장 요청을 만들지 않는다. Android 네이티브·카메라 경로 변경 없음. 새 APK 불필요.
