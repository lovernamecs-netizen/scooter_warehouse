# 출고확정 이력 고객명 — 2026-10-29

출고확정 이력에 업체·주문자명 열을 추가. OutboundCustomer의 암호화된 출고 당시 이름만 권한 있는 관리자에게 별도 POST API로 제공한다. 일반 출고 API/공유 스냅샷에는 이름을 추가하지 않는다. 미연결 과거 출고는 미등록, 비권한자는 권한 없음. 조회 감사 로그, no-store, 200건 제한, 화면 전환 시 지연 응답 폐기, textContent 표시를 유지한다.

검증: customer privacy + dispatch calendar 8개 통과. 격리 실제 Chrome에서 업체/개인/미등록 표시와 HTML 텍스트 안전 출력, 기존 캘린더 회귀 확인. Galaxy 실기기는 미검증. APK 불필요.

배포: 운영 DB 일관 백업 및 Data 백업 후 검증 커밋 fast-forward, 식별된 서버 재시작. 운영 데이터 마이그레이션 없음. 코드 롤백은 이 커밋 revert 후 재시작; 이후 업무 데이터를 과거 DB로 덮어쓰지 않는다.
