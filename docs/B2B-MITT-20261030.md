# B2B 기본품 토시 누락 수정

운영 공통 기본품은 SC/CUP만 있었고 존테스 일부만 MITT를 포함했다. 기본 B2B를 SC/CUP/MITT 각 1개로 수정한다. B2C, 차종별 쉴드/브라켓, FORZA 컵홀더 별도 전달, 주문별 제외/장착·전달 예외는 유지한다. 실제 운영 마스터에서 토시는 MITT 한 종류임을 확인했다.

server/b2b_defaults_repair.py는 명시적 운영자 실행 전용이며 서버 시작 시 자동 실행하지 않는다. 규칙 변경은 PartsBook 감사 이력에 기록한다. 승인받은 진행 B2B 주문 7d24b00b-5a58-4d21-9b4d-51542e1e90bb에 MITT 1개 미완료 작업을 추가한다. 기존 행의 품목·수량·완료·전달 수량이 하나라도 달라지면 트랜잭션을 취소한다. 추가 작업으로 출고 준비를 해제하고 재확인한다. 토시 재고는 지금 차감하지 않고 작업 완료/실제 출고 시 차감한다.

10월 27~30일 운영 조회 결과: B2B 실제 출고 1/2/3/3대, 합계 9대. 토시 Snapshot 수량 및 자동 차감은 모두 0. 해당 출고의 취소/반품 및 명시적 토시 제외 없음. 실제 전달 여부는 별도 사용자 확인 필요. 과거 18건 출고 전체나 확정 마감을 임의 수정하지 않는다.

격리 서버 테스트 88개 통과(94.89초). 검증: 신규 B2B 세 기본품·B2C 기존 규칙·FORZA 예외·출고 전 무차감·실제 출고 1회 차감·재시도 중복 방지·승인된 기존 완료 작업 보존·원장/마감 불변을 검사한다. 운영 배포 전 DB/사진 백업, 코드 fast-forward, 명시적 규칙/해당 주문 갱신 순서. DB 스키마 변경 없음. 복구 시 현재 업무를 덮어쓰지 말고 코드 revert와 기록을 남기는 규칙/주문 수정으로 처리한다.
