# 중고차 카드 삭제
기준 8bab3b6. 중고차 상품화 카드에 최초 admin(security_owner) 전용 카드 삭제 버튼 추가. 기존 상세 삭제 버튼도 같은 권한을 사용한다. 서버 delete_vehicle/archive_vehicle 양쪽에서 중고차는 최초 관리자만 허용한다. 다른 관리자·작업자·조회 계정은 403.

기존 논리 삭제를 재사용한다. 사유 및 삭제 확인 문구 필요. 활성 주문 취소 선행, 출고 이력이 있는 차량 삭제 제한 유지. 현재 재고/위치에서 제외하되 Vehicle, Stay, 사진, 상품화 프로필, 감사 이력은 삭제하지 않는다. 신차 삭제 권한은 변경하지 않는다.

격리 DB 서버 36개 테스트 통과. 최초 admin 삭제 성공·위임 관리자/작업자/조회자 거부·프로필/이력 보존·출고 실적 미생성 검사. 실제 Chrome에서 합성 중고차 카드 삭제→목록 제거→기존 Vehicle 보존 검증 통과. 실기기 미검증. 새 APK 불필요.

운영 적용 전 DB/사진 백업 후 Git fast-forward. 코드 복구는 해당 커밋 revert로 수행한다. 실제 삭제된 카드 복구는 기존 관리자 재입고 절차를 사용하며 DB를 과거 상태로 덮어쓰지 않는다.
