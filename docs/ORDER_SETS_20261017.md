# 주문 배정 세트별 장착/전달 변경

작업 위치: C:/Users/CCS/ScooterWarehouse-development/closing-inventory-20261016

## 사용 방법
차량 상세에서 B2B 또는 B2C 주문배정을 선택한다. 선택한 주문 구분은 배정 화면에서 고정된다. 기존 구분 없는 주문의 명시적 전환에서는 구분을 선택한다.
기본품은 기존 차종 ID 규칙과 품목별 장착/전달 설정으로 구성한다. B2B는 SC+컵홀더, PCX 순흥/NMAX 실버스타 쉴드이며 B2C는 SC다. 품목 용도가 미설정이면 이 주문의 초기 선택을 장착으로 표시한다. 마스터 설정은 덮어쓰지 않는다.
선택 세트에서 탑박스 블랙/레인보우+차종 브라켓 또는 EPP+차종 슬라이드짐대를 선택한다. 각 구성품은 장착/별도 전달/선택 안 함 중 선택한다. 두 품목 모두 불필요하면 세트를 없음으로 선택한다. 추가 전달 수량은 별도 예외 영역에서 입력한다.
세트를 바꾸면 이전 세트의 장착/전달 선택을 초기화하고 새 구성품을 다시 보여준다. 이미 완료된 작업을 삭제하는 변경은 기존 서버 규칙으로 차단한다.
기본품 제외·기존 장착 출처는 사유와 함께 예외 영역에서 변경한다. 공장 기본 장착은 재고를 차감하지 않으며, 창고에서 별도로 전달한 RBZ는 차감한다. 미등록 차종 호환·RBH 코드를 추측하지 않는다.

## 코드 및 데이터

server/parts_orders.py: request.set_modes.item/component에 INSTALL/DELIVERY/OMIT 저장 및 검증. 기존 요청에 이 필드가 없으면 기존 세트 장착 동작 유지.
web/product-theme.css, sw.js, index.html: 표시 및 캐시 갱신.
기존 DB 스키마와 확정 Snapshot은 변경하지 않는다. 재고 차감은 실제 출고 완료/전달 수량에만 적용한다.
