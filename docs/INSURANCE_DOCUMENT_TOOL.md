# 보험증권 PDF → JPG 관리·도구 (실험 브랜치)

## 목적 / 접근
- 좌측 **관리·도구** 메뉴 (관리자/작업자만 표시).
- 기존 창고관리, 차량/부품/사진 데이터베이스와 독립된 기능입니다.
- 브라우저에서 PDF 여러 개를 고르고 페이지별로 RGB 컬러 JPG로 변환합니다.
- 파일/연락처는 요청 메모리에서만 처리합니다. 서버 디스크·운영 DB에 보관하지 않으며, 외부 OCR·AI·클라우드 서비스에 전송하지 않습니다.
- **이번 버전에는 MMS 발송 API가 연결되어 있지 않습니다.** 서비스 선정 전 실제 문자가 발송되지 않습니다.
- 기존 CoolSMS 오류 코드/메시지를 사용자용 문장으로 변환하는 진단 화면만 제공합니다. 발송 완료/수신 완료로 표시하지 않습니다.

## 문서 원형과 가림
- **원본 PDF는 수정하지 않습니다.** 변환을 위해 복사한 개별 페이지에 기존 코드와 동일한 고정 좌표 (330, 400, 585, 435)만 흰색 비식별 처리합니다.
- 입력 페이지의 가로세로 비율, 여백, 페이지 안의 텍스트·이미지 배치를 임의로 자르거나 재구성하지 않습니다.
- 추출·렌더는 PyMuPDF, RGB 컬러 JPEG 압축은 Pillow(quality/optimize/chroma subsampling 4:4:4)를 사용합니다. 회색조 변환, 흑백 변환, 자르기, 회전, 임의 텍스트 덧씌우기를 하지 않습니다.
- JPG는 손실 압축이므로 파일의 모든 픽셀 값이 원본과 동일함을 보장할 수 없습니다. 페이지 비율은 유지되나 해상도 조정으로 글자 선명도가 저하될 수 있습니다.
- 199,000 **바이트 이하**로 압축에 성공한 이미지만 발송 준비 대상으로 분류합니다. 불가능한 경우 용량 초과 경고와 검토용 고화질 JPG를 제공하며 자동 발송하지 않습니다.
- 페이지 가림 영역이 페이지 안에 들어가지 않으면 해당 파일 전체 변환을 거부합니다. PDF 양식별 흰색 가림 위치는 실제 원본 검수 후에만 변경하세요.
- **문서 양식의 법적 유효성, 개인정보 가림의 완전성은 기술만으로 검증할 수 없습니다.** 특히 타 보험사의 서식은 사전 검수해야 합니다.

## 처리 순서
1. 관리·도구 → 보험증권 PDF 다중 선택
2. PDF 텍스트에서 차량번호 추출 (OCR 미사용). 차량번호, 차량 등록번호, 이륜차 번호, 등록번호 라벨을 우선 검색하며, 옛 지역식과 숫자형 번호를 처리합니다.
3. 본문에서만 찾거나 여러 후보가 잡히면 **확인 필요**로 표시. 원본과 대조 후 사용자가 차량번호 수정 및 **원본 확인 완료**.
4. CSV/XLSX 첫 행의 차량번호/등록번호와 연락처/전화/휴대폰을 읽어 매칭합니다. 상충하는 동일 차량번호가 여러 연락처를 가지면 자동 매칭에서 제외합니다.
5. 미리보기에서 문서 본문·가림 처리·작은 글씨·색상·비율 검수.
6. 199,000 바이트 이하/차량번호 확인 완료인 JPG만 **일괄 ZIP**으로 내려받습니다. PNG/PDF 원본을 자동 첨부·문자 발송하지 않습니다.
7. 기존 MMS 오류가 있으면 오류 코드/문구를 진단 영역에 입력해 자연어 원인과 조치, 접힌 기술 상세를 확인할 수 있습니다.

## 보안·주의
- 합성 PDF 및 가상 전화번호로만 테스트하세요. 운영 DB, 고객 신분증·보험증권·API Key를 GitHub에 추가하지 마세요.
- 브라우저에서 문서와 연락처는 현재 페이지 스크립트 메모리에 남습니다. **목록 초기화** 또는 **로그아웃**을 이용해 삭제하세요.
- 브라우저 연결이 외부에 개방된 서버라면, 업로드하는 문서가 서버를 거친다는 점을 감안하여 서버 접근권한·HTTPS를 확인하세요.
- PDF 비밀번호 보호 문서는 지원하지 않습니다.
- 이미지 첨부 용량은 문자 사업자/상품 규정이므로 실제 MMS 서비스가 결정되면 첨부 규격을 재확인해야 합니다.
- 서비스 연동 시 API Key/Secret은 브라우저나 설정 JSON에 넣지 말고 별도 보안 저장소/서버 환경에서 관리해야 합니다. 재발송 시 수신 상태 중복 검증 필수.

## 설치 및 검증 (개발 환경)
- Python 3.12 및 개발용 가상환경에서 requirements-dev.txt 설치
- 테스트: python -m pytest -q tests/test_insurance_tools.py

브랜치 코드 검토 및 합성 PDF 회귀 테스트 이후 운영 반영 여부를 결정하세요. 운영 데이터·사진·DB·환경을 덮어쓰지 않습니다.
