# 1.0.7 검증

- 서버 pytest 21개 통과: 기존 생애주기·위치 충돌·출고 롤백·마감·권한·백업 복원과 제조년월 입력/수정/가져오기/내보내기/출고 보존/DB 업그레이드.
- schema 1 형태에서 제조년월 컬럼 추가 후 기존 VIN·입고 회차 보존 및 반복 실행 확인.
- Chromium 자동 테스트: X/Esc/브라우저 뒤로가기, 작성 취소 확인, 저장 중 닫기 방지, OCR 취소·확정 후 스마트키·제조년월 보존, 출고 전달 수량·예외 사유 보존, 취소 시 서버 저장 없음. JavaScript 오류 없음.
- 재고 정렬: 제조월 우선, 같은 월 입고일 순, 미확인 마지막, 입고일 FIFO 모드, 원본 배열 보존.

실제 폴드 카메라의 초점·조명·접기/펼치기·뒤로가기 제스처와 Windows 실기기 업데이트는 현장 확인이 필요합니다. 브라우저 OCR 테스트는 네이티브 결과 콜백을 모의한 것으로, 실물 스티커 인식률 측정이 아닙니다. 인식률 수치는 보증하지 않습니다. 사진 원문과 VIN 17자리 전체를 비교한 뒤 확정하세요.

리스 사용시작/반납/고객인수 입력 화면은 이번 구현 대상이 아니며 확장 설계만 포함합니다.
