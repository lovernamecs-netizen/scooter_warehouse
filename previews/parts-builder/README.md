# 기본품·세트 구성 디자인 미리보기

운영에는 적용하지 않은 독립 HTML 프로토타입. index.html을 브라우저에서 열면 별도 서버 없이 실행된다. 운영 API 요청·저장·재고 차감은 없다. 새로고침 시 초기화된다.

2026-10-31 운영 품목 마스터의 코드/이름 및 차종별 부품 규칙만 읽어서 표시한 검토용 사본이다. 실제 고객·차량 데이터나 인증 정보는 포함하지 않는다. catalog.json 내용은 HTML에 내장되어 있다.

기능: 코드 카드, 한글 이름 툴팁, 검색/분류, 드래그 추가, 선택 후 추가, 중복 방지, 제외, 장착/별도 전달 전환, B2B/B2C, 차종별 박스·짐대 슬롯, 구성 검토 창. 품목 호환·차종 예외·권한·주문 반영·저장은 기존 서버 규칙과 연결할 때 검증해야 하며 이 시안에서는 운영 규칙을 확정하지 않는다.

실제 Chrome 로컬 파일에서 드래그/툴팁/중복 방지/제외/용도 전환/탭/세트/390px 터치 대체 조작 및 가로 넘침 확인. 실기기 미검증. 미리보기 서버 시작 명령은 자동 승인 검토에서 차단되어 네트워크 서버 없는 로컬 파일로 제공했다.

운영 배포는 사용자 디자인 확인 이후 별도 진행한다.
