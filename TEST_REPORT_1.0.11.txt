2026-10-08 검증 — 독립 DB/로컬 서버/Chromium

원인: renderPage가 지도 DOM을 교체하면서 map-viewport의 scrollLeft/scrollTop이 초기화됨.
변경: DOM에 창고 식별자와 확대 비율을 기록하고 재생성 전 시점 저장, 재생성 후 해당 창고의 시점 복원.

실제 마우스 포인터 드래그 테스트 통과:
- 가로/세로로 스크롤하고 페이지도 아래로 이동한 상태에서 구역 이동 저장
- 스크롤 X/Y, 확대 비율, 페이지 세로 위치가 모두 동일하게 유지됨
- 외곽 밖 이동 시 저장 거부 후 원래 좌표 복구 및 시점 유지
- 자재 도형 드래그 저장 후 시점 유지
- 다른 창고 선택 후 원래 창고로 돌아올 때 스크롤 복원
- 편집 모드 전환 시 시점 유지
- 확대할 때 지도 좌표에 맞춰 스크롤 배율 조정
- JavaScript pageerror 없음

업데이트 도구 검증:
- 잘못된 폴더에서 DB를 만들지 않고 중단
- 적용 및 반복 적용 전후 기존 DB SHA-256 동일
- 자동 DB 백업에 차량 레코드 보존
- 파일 교체 오류 주입 후 기존 코드와 DB 유지

서버/DB 코드는 변경하지 않았음. 1.0.10 배포 ZIP과 기준 파일의 일치를 검사함.
Windows PC 및 실제 Fold 하드웨어에서 직접 시험한 것은 아님.
